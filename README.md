## 功能

- **音乐发现**：按游戏、专辑系列和艺术家检索歌曲，支持搜索、热榜与生成随机播放列表。
- **在线播放**：播放队列、循环与随机模式。
- **沉浸式播放器**：全屏播放器、滚动歌词、歌词翻译与音频频谱可视化。
- **歌单与收藏**：创建、编辑、分享歌单，收藏歌曲和歌单。
- **互动交流**：账号登录、发表评论。
- **便捷体验**：主题与背景设置、桌面及移动端适配、快捷键操作。
